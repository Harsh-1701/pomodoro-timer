# Pomodoro Timer

A responsive Pomodoro Timer built using React and Vite.

https://roadmap.sh/projects/pomodoro-timer

## Features

- Start, stop and reset timer
- Work and break session management
- Automatic long breaks after 4 sessions
- Responsive UI
- Reusable React components

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Future Improvements

- Notification sounds
- Progress animations
- Local storage support
- Dark mode
- Deployment
